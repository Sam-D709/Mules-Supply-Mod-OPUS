Changes in this derivative are maintained by the Mules-Supply-Mod-OPUS contributors. They include the M4 shared fleet dispatcher, capacity-based allocation, multi-lot procurement, tail-demand escalation, source-stock trigger, effective-price lookup, return-home behavior, diagnostics, translations, inherited bug fixes, and portable tests/build documentation. See [README.md](README.md) for the detailed comparison and limitations.

The extension display name and description have been changed for this baseline. Original extension/order/script identifiers are retained for compatibility. Existing inline copyright and author notices in inherited source are retained. Original authors do not thereby endorse this derivative.
