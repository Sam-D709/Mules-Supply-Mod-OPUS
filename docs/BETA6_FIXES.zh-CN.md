# beta.6：存档10→11修正与清理

本地版本0.1.0-beta.6，内部668，日期2026-10-25。此文记录beta.5反馈与beta.6代码修正；beta.6尚未在原生游戏完成复测。

## 反馈证据

存档10时间395827.368，存档11时间398260.654，间隔2433.286游戏秒。Debug从395966.462开始，比起点晚139.094游戏秒，且继续写到结束存档之后；分析只统计匹配窗口。34艘M4在两个存档的忙碌数为32→19，这是瞬时状态，不能当成平均利用率。

窗口内23433次候选检查、1492次扩展（其中808次为副单），成功COMMIT共81次，却只有70条成功RESULT。11次已创建订单的尝试在COMMIT_LEG/QUEUE附近中断，遗漏父脚本中的收尾。另有11959条候选同时显示接受和失败，569次拒绝扩展仍带旧成功状态。存档11中JNE-624与DPJ-719的candidate也残留旧需求/货源。

输入快照、哈希及详细诊断保留在本机`support/seta_save03_analysis/beta5_feedback`。Debug比存档晚开始不会妨碍按游戏时间对齐，但不能补回缺失区间。

## 修正

1. **失败明确清空输出。** 原生省略命名返回值会保留调用者变量。candidate和extend在每次调用重置输出，所有失败路径明确返回空值；规划方也先清空接收变量，避免旧成功对象再次入池或被后续排序修改。
2. **消除提交中的阻塞边界。** 原生run_script即为阻塞动作，没有wait也可能让出。10个小助手统一为非阻塞动作库，53处调用改用include_interrupt_actions，使用独立前缀避免污染调用者变量。旧入口保留兼容包装，逻辑不重复。
3. **提交自己完成收尾。** 最后经济写入/回滚后立即释放本事务锁，返回前完成成功计数、退避、搜索标志、警告清理和最终RESULT。异常终止只释放自己的锁，保留已提交订单及航次身份。
4. **清理旧调度。** 删除已经不控制独立派单的船型/容量队列和基点唤醒机制；空基点不再积累历史报价。订单参数、迁移补丁及其他骡子实际使用的脚本保留。
5. **日志减噪。** 删除旧启动长清单与重复REJECT；BEGIN含build=beta.6和本轮关键参数；RESULT只记录一次，异常可标记aborted；界面失败提示只显示船号和具体原因。游戏时间戳继续保留。

## 验证

169项实际XML适配器检查通过，包含42项独立调度测试；安装包2项、31个XSD、3处原版选择器、10个动作库和64处引用检查通过。三项关键回归在保留的beta.5代码上全部失败，在beta.6全部通过：失败候选清空、失败扩展清空、提交返回处抢占仍完成收尾。

旧适配器没有正确模拟省略返回值，历史159项通过不足以排除此问题；本版已纠正并加入返回处抢占、异常清理与持锁阻塞检查。合成测试和模式验证仍不等于原生引擎调度、存档迁移、泊位等待或FPS验证。
