# v0.1.0-beta.1

首个采用独立版本号的公开测试版，X4内部版本为663。主要调整M4采购骡子；保留其他骡子行为和原扩展ID。

## 变更

- 按实际货仓容量和型号组织船队，大容量船先组合主单及副单；不足装载率的尾单从小容量船向大容量船递补。
- 合格玩家货源可优先，关闭优先后仍参与普通竞争；商品库存门槛是供货触发条件，不是强制保留库存。
- 主单按合法跳数和实际采购价选择，副单在固定主路径走廊内按偏离加价竞争；保留总范围、黑名单和交易条件。
- 单艘空闲船独立返航，修改基点后迁移搜索范围；返航检查保留移动调用栈，避免反复重启飞行和巡航充能。
- 修复等效配置快照被误判失效、站属名单重建丢失自有库存门槛的问题；保留本船失败提示和取消后重新派单。
- 删除不可执行的旧M4采购循环及两个无调用辅助脚本，补齐英文README、英文提示和直接安装包。
- 增加VERSION文件及版本发布指南，公开版本与X4内部数字版本分开维护。

## 验证与限制

116项脚本测试、2项安装包测试、24项原版XSD校验及3处补丁选择器检查通过。已有游戏反馈确认多单、容量递补、取消后重派，并在最新返航修复后确认行为生效。没有200艘船队的FPS基准，所有黑名单、优惠、模仿和存档组合仍需进一步游戏测试。

## 安装

下载附件 **Mules-Supply-Mod-OPUS-v0.1.0-beta.1.zip**；核对SHA256SUMS.txt后解压，将其中的`mules_and_warehouses_extended`文件夹放入X4的`extensions`目录。升级前移走旧模组文件夹，不要同时启用原版骡子与本分支。完整退出并重启游戏；测试建议使用存档副本。GitHub自动生成的Source code压缩包不是这个安装附件。

报告问题时请附公开版本、游戏版本、船只M4参数、触发步骤和实际表现；需要存档或日志时再补充。

## English

First independently versioned public beta; X4 internal version **663**. Focuses on M4 procurement while retaining other mule behaviors and the existing extension ID.

- Capacity-based fleet dispatch, multiple purchase lots and small-to-large tail allocation.
- Optional priority for eligible player suppliers; per-ware stock thresholds trigger supply without retaining a fixed reserve.
- Actual-price comparisons and bounded secondary-source corridors, with normal trade and blacklist checks.
- Per-ship idle return, updated home-sector searches, continuous return movement across dispatch polls, and fixes for equivalent saved configurations and stock-threshold reconstruction.
- Removed the retired M4 search loop and two unused helpers. Includes English UI resources, both READMEs and a drag-and-drop installer ZIP.

Validation: **116 script checks, 2 package checks, 24 XML schema validations and 3 native patch-selector checks passed.** User gameplay feedback confirms core dispatch and the latest return fix; large-fleet FPS and the full configuration/save matrix remain unverified.

Download the named mod ZIP under Assets, extract it, and copy its single `mules_and_warehouses_extended` folder into X4's `extensions` directory. Remove the old mod folder before upgrading, enable only one version, and fully restart the game. Chinese and English resources are included. The automatic Source code archives are not the installer.
