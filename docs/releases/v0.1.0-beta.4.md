# v0.1.0-beta.4 · 独立调度与组合采购

本地测试构建 · 2026-10-25 · 内部666 · 未公开发布。

存档3到4暴露整支船队长时间占据全局调度锁、每船重复检查大量无关买单和报价变动使草案失效的问题。本版改为每船独立规划、共享过滤索引、只在最后复核及创建订单时短暂互斥。

- 使用真实可买数量和单件体积，有限比较多个主单、同商品多厂及不同商品组合。
- 满足装载率后比较自有供货占容量比例（开启优先时），再比较预计单位时间运量，成本同级比较。
- 连续三次完整搜索因装载不足失败，第四次临时豁免；成功、配置变更或其他失败重置。
- 限制每轮192次候选配对、128次路线扩展，并轮换未处理需求和货源。
- 报价提交前重读价格，只要仍合预算/价差即可继续；保留原生预订交接、回滚及在途订单。
- 新报价事件与周期刷新结合；旧存档长派单调用栈迁移回注册入口。

说明与边界见[设计](../DESIGN.zh-CN.md)及[测试](../TESTING.zh-CN.md)。未测量新版本游戏FPS，也未完成原生存档4回放。完整退出并重启X4后再加载存档副本；已经运行的游戏不会可靠加载替换的归档。
