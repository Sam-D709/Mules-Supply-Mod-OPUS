# v0.1.0-beta.11 · 单一Debug开关（内部673）

原先需要同时开启Debug和“M4：完整候选追踪”才能得到全部候选明细，容易漏开。本版移除独立追踪选项，**开启Debug即完整记录M4候选、预筛、分级、数量刷新、任务结果和订单/交易事件；关闭即停止新的详细记录。** 旧存档里保存的独立追踪值不再限制输出。

继续使用四个日志文件、schema=3、共同会话与序号、beta.10的原生事件快照和原因汇总；不修改交易策略或M1–M3行为。开关说明同时更新日志文件位置。读档及重新开启Debug时，旧观察器和基点表通过键列表遍历，避免依赖直接遍历table。

原生事件是否正确投递仍需游戏验证。使用 `-scriptlogfiles` 启动，只需开启一个Debug开关，保存起止存档后测试。见[日志指南](../M4_DEBUG.zh-CN.md)。这是本地测试包，尚未发布GitHub Release。
