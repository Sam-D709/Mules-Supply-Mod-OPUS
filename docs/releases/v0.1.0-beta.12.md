# v0.1.0-beta.12：M4行为修复与SETA对照观测

内部版本674，日志schema=4。仅修改M4；独立扩展ID继续为mules_supply_mod_opus。本版为本地测试包，尚未发布到GitHub。

- 修复等待年龄：wave将真实等待快照作为正式参数传入plan，恢复90秒分级放宽、120/300秒的50%/25%装载阶段；兼容入口使用局部记录与嵌套存在检查。
- 修复候选批次：用明确的16次累计计数替代有整数除法歧义的判断，保留必要让出和原有192/128次搜索额度。实际加速幅度仍需游戏验证。
- 原因计数使用固定$code/$count字段的记录列表，避免X4不支持的普通字符串表键；增加总数、明细和实际检查数的一致性验证，失败明确输出LOGGER_ERROR。
- 价格先输出整数ct，再浮点除100转换Cr，原生交易另保留unitPriceCt/valueCt，避免整数Cr截断。
- 成交事件即时快照写入持久观察条目；按交易身份保持累计量，重复回调不重复累计。原生终止通知与缓存事实分开，ORDER_OUTCOME只声明已经观察到的交货量，未知原因仍为unknown。
- 每条记录附带原生SETA状态与倍率；CLOCK每10游戏秒提供本机实际时间，PHASE_TIME/YIELD与心跳提供阶段耗时、让出次数、待恢复状态及恢复间隔。周期同样受引擎调度影响。
- 提交拒绝使用稳定事件名COMMIT_REJECT；RESULT保留机器原因与可读detail。

本体依据来自当前安装的X4 8.00目录中的CAT/DAT：scriptproperties的table键、money及timewarp属性，以及common.xsd的订单与交易事件契约。订单finished时对象可能已不存在；立即cancelled可能表示重置，不单独判为贸易失败。

本地回归和模式校验只能验证其覆盖范围；SETA与普通速度各10现实分钟的原生行为复测待玩家完成。升级前退出游戏；旧wave/plan通过版本补丁退出并在下轮重建，已有订单不主动取消。测试步骤见[M4日志指南](../M4_DEBUG.zh-CN.md)。
