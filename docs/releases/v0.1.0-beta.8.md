# v0.1.0-beta.8 · M4日志观察版

内部版本670；基于beta.7策略，仅扩充诊断，供下一轮30现实分钟压测。没有修复等待年龄、搜索中断/重入或分级与预算策略；M1/M2/M3及旧共用助手不变。

M4详细日志分成lifecycle、search、orders、economy四个追加文件，使用共同会话和全局序号。增加上下层等待年龄、搜索阶段/进度/on_abort/重叠、状态心跳、需求/货源筛选计数、候选已知性、分级样本、扩展父子身份、占额交接与清仓退款。基础模式只保留有限候选样本，新增M4完整候选追踪选项。

独立MD观察器监听已登记M4的原生订单、交易、遇袭、航行和停靠事件；保存订单/trade与航次的映射，接续观察旧存档中的订单。缺失终止事件明确标为未知，取消请求与实际删除分开，不把派单成功当成交货成功。

修改过的有状态M4脚本使用版本迁移退出旧调用栈；既有原生排队订单不主动取消。升级后的观察从新会话开始，旧调用栈的历史不补造。

本地210项回归通过，包含22项日志观察测试；原版XSD结构验证通过。M1–M3及旧共用助手已核对为未改动。游戏内原生事件与30分钟压测结果待验证。

验证结果和局限见 [M4日志指南](../M4_DEBUG.zh-CN.md) 与 [测试指南](../TESTING.zh-CN.md)。本地AI/MD回归和原版XSD不能证明原生事件时序、长期运输表现或FPS。安装后需完整重启X4，再执行30分钟压测。
