# v0.1.0-beta.10 · M4日志修复（内部672）

beta.8压测出现了实际订单/转移行为，却没有原生事件记录；等待输入整行为空、原因汇总缺失，导致无法确认订单最终数量和等待值的丢失位置。本版本修复这些观察路径，保留beta.7交易策略及beta.9独立安装标识。

- 15个原生子回调显式绑定各自Register父实例的飞船/驾驶员。事件发生时保存可用的订单/交易数量、价格和时间，保留两个交易参数身份，按精确交易关联选择快照。取消请求和订单完成仍不等于全量交货。
- 等待字段先独立读取再格式化，分别记录wave与plan采用值，区分缺失、空值和零；不调整等待年龄、装载门槛或分级策略。
- 原因计数显式初始化并通过键列表输出。提前退出/中断也输出部分统计；基础/完整模式使用相同计数，汇总输出数量与省略数量。
- 基础模式候选刷新最多3条，保留每类候选/预筛前2条和分级暂缓最多3条；完整追踪偏好保持用户设置。
- 心跳区分对象存在与搜索观察状态，不再宣称对象存在就代表搜索在运行。新增WATCH_READY、原生回调数量、覆盖缺口和格式化失败信息。
- schema=3单独标注模组/日志/策略版本；固定事件名与提交原因码，消息回车换行转义，四文件共同序号继续保留。

所有修改在support源码完成。M1–M3、旧共用助手及语言资源保持不变。规划器版本升至14，旧存档中执行到一半的旧规划器返回后重新搜索，已排队订单保留。

本地验证包括实际XML动作回归、独立子命名空间下的回调求值、对象消失前的数量捕获、完整/部分计数、采样边界、XSD和可复现安装包检查。**这些检查不能证明游戏已恢复原生事件投递，短测和30分钟SETA压测尚待玩家执行。**

本版是本地测试包，尚未发布GitHub Release。安装目录仍为 `extensions/mules_supply_mod_opus`；完整退出X4后替换，勿与原版骡子同时启用。测试步骤见 [M4日志指南](../M4_DEBUG.zh-CN.md)。
