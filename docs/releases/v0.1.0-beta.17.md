# v0.1.0-beta.17 / 内部679：M4货源排序与评分

M4不再因为货源属于玩家而提高排序；小额自有货源不能再通过所有权加分挤掉足量NPC货源。玩家工厂继续参与相同的可售数量、距离和整趟吞吐比较。

- 删除粗筛专属自有名额、路线预选所有权加分、整趟自有占比奖励及相应中间状态。隐藏旧“优先从玩家进货”参数；旧存档、模仿和下属同步中的值均不再影响排序或使合法草案失效。
- 自有占比整数除法问题随该项评分删除而消失。吞吐效率改为百万倍率定点整数：先将体积转64位并乘1000000，再除时间权重。预选效率采用同样精度。
- 满足装载门槛的状态仍优先保留，再按效率排序；使用两组排序表，不把优先级与效率塞进同一个巨额常量。搜索宽度、候选192/路线128预算不变。
- 玩家库存供货门槛、原生报价/预订、资金、黑名单、泊位、无人机、内部免费调拨及价差规则保留。库存指合法可售量，不是工厂全部实物库存。
- M1–M3、货量分级、90秒/3次miss放宽、装载2/5/10分钟放宽和失败退避策略不改。
- 日志schema=8、strategy=beta.17、scoreScale=1000000。BEST删除ownedVolume和旧quality；score是放大后的整数，etaWeight仍是启发式时间权重。四路文件和单一Debug开关保留，ct/Cr格式不变。
