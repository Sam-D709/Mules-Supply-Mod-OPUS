# v0.1.0-beta.9 · Steam创意工坊身份隔离热修复

内部版本671；日期2026-10-25。

本次GitHub公开更新相对上一公开版beta.3，包含两项主要变化：

- 修复创意工坊 ID和原版骡子模组冲突问题。
- 优化SETA下货船接单的逻辑。

SETA相关调整累积自beta.4—beta.7；beta.9相对beta.8的运行脚本保持一致。已确认的等待年龄与日志问题仍列为已知限制。

beta.8及以前沿用了原版骡子的Steam创意工坊ID，并安装在原版目录内，原版更新可能覆盖本项目。beta.9改用独立本地扩展ID `mules_supply_mod_opus`，安装包顶层目录同为 `mules_supply_mod_opus`，构建校验也固定检查新身份。

## 安装和迁移

1. 保存并退出X4，备份存档和已有骡子目录。
2. 将旧版项目所在的 `extensions/mules_and_warehouses_extended` 移到 `extensions` 之外。不要只把新包覆盖进旧目录。
3. 解压本版ZIP，把 `mules_supply_mod_opus` 文件夹放入游戏 `extensions`，使 `extensions/mules_supply_mod_opus/content.xml` 存在。
4. 退订Steam上的原版骡子，或在游戏扩展菜单禁用原版。Steam仍可更新已订阅原版自己的目录，但它与本项目的新目录分离。两者含同名脚本和行为，不能同时启用。
5. 启动游戏确认Mules-Supply-Mod-OPUS已启用，加载备份存档并检查船只行为；若旧行为需要重新选择，重新设置M4。扩展ID改变后的存档迁移尚需原生游戏验收，不承诺所有旧存档/第三方补丁自动识别新身份。

可选依赖SirNukes Mod Support APIs的创意工坊ID属于该依赖自身，保持原样。来源说明及历史版本文档中出现的旧ID也不代表当前扩展与原版关联。

## 范围与验证

只变更安装身份、公开版本、内部版本、构建规则和文档。AI/MD/语言/库XML及CAT/DAT与beta.8逐字节一致；M1–M4交易逻辑不变。beta.8的日志与等待年龄问题尚未修复，日志中的 `build=beta.8` 表示沿用该版诊断实现。

安装包测试验证独立目录、独立ID、保留可选依赖、解包内容及重复构建一致性。实装迁移前备份旧目录，安装后逐文件核对新包。没有更改Steam订阅、Steam清单、原版下载目录或玩家存档。
