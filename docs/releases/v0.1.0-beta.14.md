# v0.1.0-beta.14：M4日志金额与正文修复

内部版本676，日志schema=6；贸易策略保持beta.12。本地测试版，原生游戏短测尚待执行。

- 将四路SESSION常量头独立写出，避免会话头依赖金额探针或长格式表达式；会话元数据和探针分别记录。

- 保持单一Debug开关、四个日志文件、M1–M3、贸易规则、搜索额度和调度/让出行为。

验证顺序：本地静态检查与适配器测试；游戏内短测检查四个SESSION头、money probe、CANDIDATE、ORDER_CREATED和明细覆盖字段；全部通过后再长时间压测。详细步骤见[测试指南](../M4_DEBUG.zh-CN.md)。
