# v0.1.0-beta.13：M4日志补齐

内部版本675，日志schema=5，贸易策略仍为beta.12。本版为本地测试包，尚未发布到GitHub；扩展ID继续为mules_supply_mod_opus。

- 显式使用原生largefloat除数100F转换Cr，保留整数ct。SESSION增加1223ct→12.23Cr已知值探针，moneyProbeValid应为true；其原生运行结果需在下一轮游戏日志验收。
- 覆盖提交初始资格、报价/价格/库存复核、锁占用、数量/资金/绑定复核及创建失败回滚后的正常拒绝出口。每次调用仅输出一次COMMIT_REJECT，附stage/code/detail和逐腿COMMIT_REJECT_LEG；COMMIT_CHECK另保留具体复核失败及报价资格原因代码。中断和版本迁移仍按原有中断终态观察。
- SEARCH_CONSTRAINTS及RESULT分别记录枚举截断、额度、分级推迟、可接受状态数、装载不合格状态数、草稿装载率及是否有合格方案。旧status和loadRejected语义保留；budget不再被误读为唯一约束或资金不足。
- 每条事件附本机wall时间；会话标识组合现实时间、游戏时间、递增序号与调用对象，便于区别读档/重新开启Debug。跨运行分析仍需保留日志来源，不能假定字符串绝对唯一。
- 保持一个Debug开关和四类日志文件，保留逐船/轮次/航次/订单/交易关联。ORDER_GONE缺失历史继续标未知，不能补写为确定失败。

与冻结beta.12相比，仅5个M4运行XML改变，35个运行XML哈希一致；移除Debug分支后，plan/commit/journal的经济动作完全一致。交易规则、等待批次、搜索额度及M1–M3未改；没有增加阻塞动作。

验证：235项回归（含45项日志观察）、本体XSD和动作库引用校验；安装包另有2项解包/可复现检查。本地适配器不能代替本体浮点、事件投递和SETA调度验收。等游戏时间测试步骤见[M4日志指南](../M4_DEBUG.zh-CN.md)。
