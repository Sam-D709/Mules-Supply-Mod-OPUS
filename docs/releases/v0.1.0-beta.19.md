# v0.1.0-beta.19：移除NPC货源许可选项

内部681，日志schema=8，策略标记beta.19。

M4不再显示“从AI派系中收集”。所有合格玩家与NPC卖报价自动进入候选比较；移除粗筛、候选和提交阶段对旧NPC许可值的限制。旧参数保留为内部兼容字段，统一为true；旧存档false、模仿命令、船队名单重建和复制签名均不能恢复禁用效果。配置签名升级为v20，旧搜索与运行入口通过版本补丁退出或重建，现有贸易订单不主动取消。

原生报价资格、贸易规则、黑名单、路线、停靠、无人机、资金、报价净量和预订检查保留。M1–M3及其模仿分支、分级、装载等待降级、192/128搜索限额、路线评分均不修改。Debug仍为单一开关和四个阶段文件；CONFIG/BEGIN明确supplierPolicy=all_native_eligible，allowAI=1表示固定生效策略，不再是可调开关。失效货源的SOURCE_FILTER记录source_unavailable及not_queried，不把未查询净量写成0。

本地验证：249项适配器测试，含旧false仍能采购NPC、配置身份稳定、旧v19配置失效、模仿参数归一化、原生黑名单仍阻止采购，以及真实失效报价的日志计数回归。另做安装包测试、原生XSD与引用校验。适配器不替代原生游戏调度和存读档验收。

beta.18存档4→2压测证据已冻结到本地support/beta18_pressure；704条QUEUE与ORDER_CREATED成对，四路SESSION/金额探针正常，351条BEST评分核对通过。该结论属于beta.18，不能追认为beta.19已完成游戏验收。

正常退出游戏后备份实装再安装。保留旧存档4、2，建议从终点2继续，等读档稳定后确认选项消失。保持SETA关闭，开启Debug（若原已开启则读档自动新建SESSION），待初始化后暂停另存新基点，再解除暂停并开SETA；结束时先暂停、保存新终点，再关闭Debug并正常退出。无需在刚读档瞬间抢暂停。不要覆盖本轮证据，记录新基点/终点槽位；当前无需重新单独验证旧金额修复。
