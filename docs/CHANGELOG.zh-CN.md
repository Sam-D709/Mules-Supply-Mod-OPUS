# 变更记录

## v0.1.0-beta.1 · 首个独立版本公开测试（2026-10-23）

- 采用独立公开版本号 `0.1.0-beta.1`，X4内部版本从662升至663；公开编号写入VERSION，打包工具据此命名。新增版本规范与后续发布指南。
- 打包内容包含本轮返航修复、代码清理、英文适配和前期玩家货源优先级调整。详细[发布说明](releases/v0.1.0-beta.1.md)。

### 返航与代码清理

- 根据存档14追踪返航反复重发：星区基点使用真实普通区域作为移动锚点，避免原版移动脚本因空星区上下文提前结束。
- 返航每30秒检查新任务，保留原移动调用栈；无任务时不再周期性终止飞行，不干扰原版巡航充能。停止信号使用逐船递增序号，旧定时信号不能影响新的返航。
- 配置有效性改为核对订单来源、设置签名和绑定状态，允许内容相同的存档快照；真实设置改变仍拒绝旧草案。
- 船队名单重建补传玩家库存门槛，保留0%、60%、100%等各船设置。
- 删除M4入口中424行无法执行的旧搜索及其准备代码，移除仅供旧搜索使用的报价评估和快速排序脚本；停止转发三个废弃参数。兼容参数定义、存档迁移补丁及其他骡子仍依赖的脚本保留。
- 验证：116项脚本检查、2项安装包检查、24个XML结构校验、3处原版补丁选择器通过。玩家已确认最新修复生效，更多返航场景仍可按测试表I19—I21复测。

## 662 · 玩家货源优先级（2026-10-22）
- 修复修改基点星区后仍沿用旧配置的问题：直接 M4 从当前行为订单读取基点，迁移共享调度成员并重建新基点索引；旧基点停止为该船搜索与返航。保留已排队贸易及预订，模仿行为仍采用传入的基点。日志新增 `HOME_CHANGED`。
- 空闲返航改为逐船判断：本船没有活动或排队命令、未由玩家驾驶即可返回，其他 M4 忙碌不再阻止返航。站基点返回站附近，星区基点进入该星区即可；保留黑名单检查和返航途中重新接单机制。

- 增加可安装预发布包的本地构建：`Mules-Supply-Mod-OPUS-v6.62.zip`，后续可作为GitHub Release附件。解压后将单个模组文件夹拖入extensions即可；升级先移走旧目录。附SHA256校验文件。
- 新增英文README及中英文入口；完善英文M4参数说明，把两处写死中文的警告改为中英文本引用。打包时从默认英文源生成l044资源，避免两份英文维护不一致。
- 打包工具验证实际解压结构、全部归档内容和必需文件；两个独立安装包测试覆盖源码一致性与可复现构建。
- 将 M4 的“启用从玩家工厂进货”改为“优先从玩家进货”。保留内部参数名和已有开关值，兼容旧订单。
- 开启：对每笔主单或副单，合格玩家货源优先于NPC；同层级仍按主单距离/价格、副单偏离估价排序。自有货源不可执行或数量不足时，可继续从NPC补足。
- 关闭：不再排除玩家货源；库存过门槛的玩家工厂与NPC按相同排序规则竞争。实际所有权、付款及内部调拨规则不变。
- 库存必须严格超过门槛，两种模式均有效。范围、黑名单、停靠、无人机、资金、可售数量与最大笔数等检查不变。NPC货源开关仍只控制NPC。
- 模仿行为补传库存门槛，正确保留0%；缺字段的旧订单使用50%。更新脚本版本和配置签名，让旧缓存及未提交草案按新逻辑重算。
- 候选日志增加优先开关和货源层级，更新中英界面、README、详细设计及游戏测试表。保留仓库已有README修改。
- 验证：116项脚本检查、2项安装包检查通过；26个XML结构校验及3处补丁选择器检查通过。原生游戏中的新优先级、模仿行为及英文显示尚待实测。
